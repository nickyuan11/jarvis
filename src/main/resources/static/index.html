提醒设置

填写邮箱并开启后，提醒到点时会同时发一封邮件，即使没打开 Jarvis 也能收到。邮箱只用于发送提醒。

我的资料

上传 .txt 或 .md 文件（每个不超过 1 MB）。处理完成后，就可以在对话里问 Jarvis 资料里的内容，回答会注明出处。删除的资料在回收站保留 7 天。

    Jarvis 记得的事

    这些信息会在每次对话时提供给 Jarvis，让它更了解你。除了你让它记住的，它也会在聊天结束后自动记下一些。你可以随时添加或删除；删除后 Jarvis 就不再知道这件事。银行卡号、身份证号、密码不会被保存。
